# Training 4 - Aelion

Projet de formation pour l'analyse d'incidents et la gestion de données.

## 📁 Structure du Projet
- `src/` : Code source principal.
- `config/` : Configuration (Alembic, Docker).
- `scripts/` : Scripts utilitaires (SQL, initialisation).
- `notebooks/` : Notebooks Jupyter pour l'analyse.
- `tests/` : Tests unitaires et d'intégration.
- `docs/` : Documentation.
